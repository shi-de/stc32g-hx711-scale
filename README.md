# STC32G HX711 电子秤

基于 STC32G12K128 系列单片机、HX711 和 SPI TFT 的电子秤固件。

## 功能

- HX711 24 位采集、去极值平均滤波和采集超时处理。
- 去皮、标准砝码标定、g/kg 显示切换。
- 稳定状态提示、峰值记录开关、IAP 参数掉电保存。
- 中文菜单和按键交互。

| 文件 | 用途 |

## 编译

使用 Keil μVision 和 C251/PK251 工具链打开 `UART1.uvproj`，安装相应 STC 器件支持后编译。该项目使用 C251 扩展，不能直接用桌面 GCC 编译主程序。

原工程引用了外部 `comm/STC32G.h`；本仓库将资料包中对应头文件放在工程根目录并修正引用。系统时钟配置为 22.1184 MHz。

## 连接与操作

HX711：SCK 接 P4.0，DT 接 P4.1。TFT 使用 P2.2 CS、P2.3 SDA、P2.5 SCL、P2.1 DC、P2.6 RST、P2.0 背光。实际供电、电平和按键布线应以硬件原理图及代码为准。

称重页：A 进入菜单，B 去皮，C 切换单位，D 切换峰值记录。

标定时先空秤进入菜单并选择标定，程序记录零点；再放置标准砝码，设置质量后确认。标定页 B/C 调整质量，D 确认，A 返回。

重量计算：`重量(g) = (采样值 - 零点) / 每克计数`。默认系数 430 仅用于估算，必须按实际传感器标定。稳定阈值是原始采样计数差，不是克数。
